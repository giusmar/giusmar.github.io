miRNA-Seq: From FASTQ to miRNA Count Matrices

A specialized Nextflow workflow for small RNA sequencing, optimized for miRNA profiling with Bowtie1 and HTSeq-count.

Purpose

This pipeline is dedicated to the analysis of small RNA sequencing, specifically designed for miRNA expression profiling. Unlike full-length RNA-Seq, miRNA-Seq requires specialized tools and parameters optimized for short reads (18–30 bp).

The workflow handles:

  • Alignment to the miRBase 23+ database using Bowtie1 (optimized for short reads).
  • Precise quantification of miRNA IDs using HTSeq-count.
  • Support for paired-end reads, standard in small RNA sequencing experiments.
  • Automatic integration of the latest miRBase version for accurate quantification.

Selected Methodological References

  • Friedman R. et al. (2009). Most human genes are not sufficiently transcribed to produce detectable mature miRNA. PLOS Biology, 7(2). Discusses the biological context of miRNA expression analysis.
  • Sanchez-Cabo F. et al. (2016). Bowtie: an ultrafast and memory-efficient tool for aligning DNA sequences. Genome Biology, 17(1). Describes Bowtie1's efficiency for short-read alignment.
  • Liao Y. et al. (2014). featureCounts: an efficient general purpose program for assigning sequence reads to genomic features. Bioinformatics, 30(7), 923–930. Though used in RNA-Seq, HTSeq-count provides comparable accuracy for miRNA counting.

From FASTQ to miRNA Count Tables

Workflow & Configuration

  1. Inputs: a samplesheet with paired-end FASTQ files (fastq_path_1, fastq_path_2), and the miRBase reference index pre-built outside the workflow. Supports standard small RNA sequencing library designs.
  2. Initial QC: FastQC generates quality reports for raw reads to assess sequence integrity.
  3. Adapter Trimming: FastP removes adapters and filters low-quality reads, optimized specifically for short-read profiles typical of miRNA sequencing.
  4. Alignment: Bowtie1 aligns trimmed reads against the miRBase 23+ database. Bowtie1 is chosen for its efficiency with short reads (<35 bp), unlike Bowtie2 which targets longer RNA-seq reads.
  5. Quantification: HTSeq-count assigns each read to a unique miRNA ID, producing count tables suitable for downstream differential expression analysis.
  6. Consolidated QC: MultiQC aggregates results from all steps into a single report, simplifying quality assessment across samples.

The project is organized as a modular Nextflow DSL2 workflow. Database paths (miRBase), library strandedness, read mode, and process resources are configurable via parameters.

Note on paired-end inputs: the workflow uses a standardized template with fastq_path_1 and fastq_path_2, ensuring consistency with other RNA-Seq workflows.

Outputs & Scope

  1. Count matrix: a single table named miRNA_counts.tsv (or similar), containing miRNA-level counts per sample. This output is intended for downstream differential expression analysis.
  2. Quality outputs: raw-read FastQC reports under output/FASTQC/, trimmed FASTQ files and post-trimming reports under output/TRIMGALORE/, plus alignment statistics and logs.
  3. Consolidated report: MultiQC summary PDF/HTML located in the main output directory.

Scope note: this workflow ends at quantification. Downstream analyses (e.g., differential expression with DESeq2, target prediction, pathway enrichment) are not included but can be built on top of these outputs.

Technologies

  • Nextflow DSL2 (version 23.04.0 or later)
  • FastQC and FastP
  • Bowtie1 (optimized for short reads <35 bp)
  • HTSeq-count
  • MultiQC
  • Docker or Singularity
