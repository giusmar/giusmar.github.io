How I work and how I can help

Every project starts with a biological question. I turn complex data into reproducible analyses and clear results, choosing tools and follow-up analyses to address the question that matters.

Starting with the biological question

I analyse transcriptomes using 3′ mRNA-Seq, total RNA, full-length RNA and miRNA approaches, tailoring analyses and reports to uncover the most relevant insights.

Making analyses reproducible

I build scalable pipelines and cloud environments, integrating data, infrastructure and workflow tools to support analysis from setup through to results.

Exploring complex data

I also work with clinical and omics data using tailored analyses and machine-learning models, keeping the interpretation of the problem at the centre.

Preparing and assessing data

From preprocessing to quality control, I prepare data for reliable analysis. Where relevant, I also use Kraken2 for taxonomic classification to investigate contamination and microbial composition.
